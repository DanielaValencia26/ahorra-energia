# Ahorra energía en casa

Sitio web en HTML5 y Bootstrap 5 sobre el consumo de energía de mi casa y el efecto de El Niño 2026.

**Sitio publicado:** https://danielavalencia26.github.io/ahorra-energia/

## Páginas
- `index.html`: cómo afecta El Niño 2026 a mi casa, con la tabla y la gráfica del precio de bolsa.
- `equipos.html`: consumo semanal de 4 equipos de mi casa, con las fotos de sus etiquetas.
- `registro.html`: formulario para registrar un equipo.
- `mi-factura.html`: historial de mi factura, comparación con la proyección y recomendaciones de ahorro.
- `encuesta.html`: encuesta de hábitos de consumo de energía.
